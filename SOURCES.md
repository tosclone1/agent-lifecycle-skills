# Sources and Provenance

This repository contains original work. Its design was conceptually informed
by several public skill collections:

- **mattpocock/skills** — MIT. Concepts informing disciplined diagnosis,
  test-driven development, domain modeling, and multi-axis review.
- **Jeffallan/claude-skills** — MIT. Concepts informing spec mining and
  technology-specialist skills (none of those skills are included in this
  export).
- **anthropics/skills** — Apache-2.0 examples informing progressive
  disclosure and skill creation/evaluation practices.
- **markdown-viewer/skills** — GPL-3.0. Used only as conceptual inspiration
  for visualization categories; no GPL implementation text or assets are
  copied into this repository.

No upstream code or substantial text is directly incorporated. The exported
skills (continuity review, lifecycle policies, regression guard, production
validation, deployment safety, project profiles, and the activation CLI) are
original concise implementations.

If you incorporate upstream code or substantial text in the future, retain
the required upstream notices and update this file.
